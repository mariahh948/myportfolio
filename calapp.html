Calculator

A simple, responsive calculator application that performs basic mathematical operations.

Role: Frontend Developer

Designed and developed a calculator application by following a guided tutorial, then customized the layout, styling, and user interface to reinforce my understanding of HTML, CSS, and JavaScript.

Features

  • Perform addition, subtraction, multipulication, and division
  • Supports decimal calculations
  • Clear button to reset calculations
  • Displays the current expression and result
  • Responsive interface for desktop and mobile devices

Improved my ability to organize JavaScript into reusable functions.

Gained experience debugging application logic and fixing event-handling issues.
