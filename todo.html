To-Do List

A simple, responsive to-do list app with task persistence, built using HTML, CSS, and JavaScript.

Role: Frontend Developer

Designed and developed a to-do list application by following a guided tutorial, then customized the layout, styling, and structure.

Features

  • Add, edit, and delete tasks
  • Mark tasks as complete/incomplete
  • Tasks persist between session
  • Responsive UI
  • Navigation

What I learned:

Learned how to use browser storage (localStorage) to persist data between sessions.

Improved my understanding of DOM manipulation and event-driven JavaScript.

Learned responsive web development principles.

Gained hands-on experience building and structuring a functional web app.

Technologies used

  • HTML
  • CSS
  • JavaScript
